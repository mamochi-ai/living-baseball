# リビング・ピンポン野球 開発キット

このZIPをClaude Codeへ渡して、CLAUDE_CODE_PROMPT.mdを読んで実装するよう依頼してください。

- 個別PNG：投手12枚、打者12枚、小物9枚、リビング背景1枚。
- reference/visual_target.png：完成イメージ（背景として使わない）。
- reference/frames_review.jpg：切り出し確認用。
- reference/safe_zones_preview.jpg：セーフ範囲の仮指定。1＝カーテン間、2＝右のドア、3＝カレンダー付近、4＝左奥のタンスの上。
- zones.initial.json：編集できる判定範囲の初期値。
- assets/manifest.json：画像の順番・寸法・アンカー情報。

セーフ範囲以外はアウト。投手守備範囲もアウト。画像の場所だけで即判定せず、球の奥行きと先に当たった物を考慮する設計です。

人物シートの番号を除き、個別画像を共通キャンバスに配置して足元をそろえました。生成画像の細かな動作差・一部原画端の欠けは残り、滑らかな連続アニメーションや実機動作を保証する完成ゲーム素材ではありません。特に打者06→07は実装時の確認対象です。小物は個別画像ですが、ガラス片は集合、割れた花瓶は破片と花の集合です。

今回は画像分割・仕様書・設定のキットです。ゲーム本体、3Dモデル、音声素材は含みません。別プロジェクトのnote素材は入れていません。
